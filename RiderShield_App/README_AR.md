# RiderShield — تطبيق الهاتف المحمول

## نبذة عن التطبيق

تطبيق RiderShield هو جزء من مشروع تخرج في قسم تقنية المعلومات بجامعة الملك سعود، تم تطويره باستخدام Flutter وDart بهدف تعزيز سلامة قائدي الدراجات النارية.

## الواجهات والخصائص

### تسجيل الدخول وإنشاء الحساب

- واجهة تسجيل الدخول.
- واجهة إنشاء حساب جديد.
- التحقق من صحة المدخلات.
- شروط إنشاء كلمة المرور.
- مؤشر قوة كلمة المرور.
- واجهة تسجيل الدخول باستخدام Google.
- تسجيل الخروج.

### الصفحة الرئيسية (Home)

- عرض نموذج ثلاثي الأبعاد للخوذة مع إمكانية تدويره.
- عرض حالة اتصال الخوذة.
- عرض إحصائيات السلامة والتحذيرات.
- تخصيص مدة العد التنازلي للطوارئ من 5 إلى 60 ثانية، بمدة افتراضية تبلغ 10 ثوانٍ.

### الاتصال بالخوذة (Connect Helmet)

- واجهة الاتصال بالخوذة وفصل الاتصال.
- عرض مراحل الاتصال بصورة متحركة.
- عرض حالة الاتصال.
- إرشادات توضح خطوات الاتصال بالخوذة.

### الطوارئ (Emergency)

- إضافة جهات اتصال الطوارئ وتعديلها وحذفها.
- حفظ اسم جهة الاتصال ورقم الهاتف وصلة القرابة.
- واجهة طلب المساعدة اليدوي (Manual SOS).
- واجهة التنبيه عند وقوع حادث.
- عد تنازلي قابل للتخصيص.
- إمكانية إرسال طلب المساعدة اليدوي دون انتظار انتهاء العد التنازلي.
- إمكانية إلغاء التنبيه باستخدام زر I'm OK.
- العودة تلقائيًا إلى الصفحة الرئيسية عند إلغاء التنبيه.
- العودة تلقائيًا إلى الصفحة الرئيسية عند قبول طلب الطوارئ.
- تسجيل الحادث عند انتهاء العد التنازلي الخاص بالحوادث.
- إمكانية فتح تطبيق الرسائل عند تعذر الإرسال التلقائي.

لا يتم تسجيل حادث عند إلغاء التنبيه، كما أن طلب المساعدة اليدوي لا يُسجل باعتباره حادثًا.

### تقارير السلامة (Safety Reports)

- عرض سجل الحوادث.
- عرض سجل التحذيرات.
- عرض تحذيرات السرعة.
- عرض تحذيرات النعاس.
- عرض تحذيرات اقتراب المركبات.
- تصفية التقارير حسب التاريخ.
- عرض تفاصيل السجلات.
- حذف السجلات.

### الملف الشخصي (Profile)

- تعديل المعلومات الشخصية.
- تغيير صورة الملف الشخصي.
- تغيير صورة الغلاف.
- تعديل مستوى خبرة القيادة.
- واجهة تغيير كلمة المرور.
- إعدادات الخصوصية والحماية.
- التبديل بين الوضع الفاتح والوضع الداكن.
- تسجيل الخروج.

## تصميم التطبيق

- دعم الوضع الفاتح (Light Mode).
- دعم الوضع الداكن (Dark Mode).
- تصميم زجاجي للواجهات.
- شريط تنقل سفلي عائم ومخصص.
- انتقالات متحركة بين الصفحات.
- نماذج ثلاثية الأبعاد للخوذة.
- حقول إدخال مجمعة ومتناسقة.
- عناصر واجهة قابلة لإعادة الاستخدام.

## التنقل داخل التطبيق

يتكون شريط التنقل السفلي من ثلاث صفحات رئيسية:

- Home
- Emergency
- Connect Helmet

يمكن الوصول إلى صفحتي Safety Reports وProfile من الشريط العلوي للتطبيق.

## التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| Flutter | تطوير تطبيق الهاتف المحمول |
| Dart | لغة البرمجة |
| Shared Preferences | تخزين البيانات محليًا |
| Image Picker | اختيار الصور |
| GLBView | عرض النماذج ثلاثية الأبعاد |
| URL Launcher | فتح التطبيقات الخارجية |
| Android SDK | دعم تشغيل التطبيق على Android |

## هيكلة المشروع

- `lib/main.dart`: نقطة تشغيل التطبيق.
- `lib/app/`: إدارة حالة التطبيق وإعداداته.
- `lib/screens/`: واجهات التطبيق.
- `lib/widgets/`: عناصر الواجهات المشتركة.
- `lib/theme/`: الألوان وأنماط التصميم.
- `lib/navigation/`: التنقل بين الصفحات.
- `lib/services/`: خدمات التطبيق.
- `lib/utils/`: الوظائف المساعدة.
- `assets/images/`: الصور ونماذج الخوذة ثلاثية الأبعاد.
- `android/`: إعدادات منصة Android.
- `pubspec.yaml`: مكتبات المشروع وملفات الموارد.

### خطوات التشغيل

افتح مجلد `RiderShield_App` الذي يحتوي على ملف `pubspec.yaml`.

التحقق من بيئة التطوير:

```bash
flutter doctor
```

تثبيت المكتبات المطلوبة:

```bash
flutter pub get
```

عرض الأجهزة المتاحة:

```bash
flutter devices
```

تشغيل التطبيق:

```bash
flutter run
```

- صور الملف الشخصي والغلاف.
- جهات اتصال الطوارئ.
- سجلات التحذيرات.
- سجلات الحوادث.
- مدة العد التنازلي للطوارئ.
- البيانات المرتبطة بكل حساب محليًا.
